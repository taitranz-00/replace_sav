🎯 3 LỆNH CHÍNH - SIÊU ĐỠN GIẢN
════════════════════════════════════════════════════════════════

1️⃣  SAV → JSON (để edit)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
python sav_to_json.py Active.sav edit.json

→ Tạo file JSON dễ đọc và chỉnh sửa


2️⃣  EDIT JSON FILE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
notepad edit.json
# hoặc
code edit.json

→ Sửa giá trị "value" trong file JSON


3️⃣  JSON → SAV (tạo file mới)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
python json_to_sav.py edit.json Active.sav Active_new.sav

→ Tạo file SAV mới với thay đổi


4️⃣  SO SÁNH 2 FILE (check thay đổi)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
python compare_sav.py Active.sav Active_new.sav

→ Xem có bao nhiêu thay đổi


════════════════════════════════════════════════════════════════
📝 VÍ DỤ EDIT JSON
════════════════════════════════════════════════════════════════

File edit.json:
{
  "Gyroscope": {
    "type": "IntProperty",
    "value": 5          ← Sửa đây (từ 1 → 5)
  },
  "FPSLevel": {
    "type": "IntProperty",
    "value": 10         ← Sửa đây (từ 8 → 10)
  }
}

⚠️  CHÚ Ý:
   - Chỉ sửa số sau "value"
   - KHÔNG sửa "type"
   - KHÔNG xóa dấu ngoặc {}

🆘 TROUBLESHOOTING
════════════════════════════════════════════════════════════════

Q: File JSON bị lỗi syntax?
A: Kiểm tra dấu ngoặc {}, dấu phẩy cuối dòng

Q: Không thấy thay đổi trong game?
A: Đảm bảo đã copy file mới vào đúng folder

Q: File SAV bị lỗi?
A: Restore từ Active.sav.backup
